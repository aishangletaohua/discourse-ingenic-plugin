## 1. 论坛是什么

Ingenic 社区论坛是一个标准 Discourse 论坛，在论坛之下增加了一个开发者专区。帖子、分类、标签、搜索、通知、举报等全部是 Discourse 原生能力；扩展增加了四类 Ingenic 特有的内容：

- **芯片文档**：跟随产品树组织，并且分版本。
- **下载中心**：SDK、固件、手册和工具，分三层访问权限，带申请审核流程。
- **开发板与样片目录**：每张卡片可以带申请链接和购买链接。
- **贡献体系**：帮助他人获得积分，会员还可以用积分给自己的问题挂悬赏。

另有两个可选集成把论坛接到 AI 工具上：**MCP 服务器**页面和**悬浮助手**。两者都依赖站点管理员单独开启的功能。

论坛是双语的。界面语言在顶部切换；文档、下载和开发板记录各自可以带语言。登录方式没有被改动：站点配置了哪些方式（邮箱、Google、GitHub 等），就使用哪些方式。

## 2. 需求汇总

项目是分阶段长出来的。下表每一行是当时确认的需求、为它实现的内容，以及读者在哪里能看到。

| # | 需求 | 交付内容 | 在哪里看到 |
| --- | --- | --- | --- |
| 1 | 保留 Discourse 原生论坛，在其下增加 Ingenic 开发者专区，而不是替换论坛 | 原生帖子、分类、标签和侧边栏保留；插件与主题并列安装 | 整个论坛 |
| 2 | 带产品层级的在线文档 | 系列 → 芯片两级产品树、分版本页面、Markdown 阅读器、目录树、全文检索 | `/ingenic/docs` |
| 3 | 版本之间不重复保存每一页 | 一个版本只存它改过的页面，其余页面继承最近的更早版本 | 版本选择器；后台 → 文档 |
| 4 | 在后台管理文档 | 建系列、芯片、版本和页面；排序、改名；覆盖或恢复继承 | 后台 → 插件 → Ingenic |
| 5 | SDK/固件下载，三层访问权限 | 登录即可、填写开发者信息、申请加审核；文件存放在 Web 根目录之外，校验后流式返回 | `/ingenic/downloads` |
| 6 | 带邮件通知和按账号授权的申请流程 | 申请队列、邮件通知团队邮箱、通过/拒绝、可撤销并可设置有效期的授权 | 后台 → 下载 → 申请 / 授权 |
| 7 | 开发板目录 | 开发板与样片按芯片归档，类型、系列、芯片三层按钮筛选、卡片和详情弹窗 | `/ingenic/boards` |

| 10 | 贡献积分 | 规则表、只追加的流水、余额、会员明细、下载消费 | `/ingenic/points`；后台 → 积分 |
| 11 | 问题上的高价值悬赏 | 积分在提问者话题上托管，采纳答案即支付，撤回、过期或删帖退款 | `/ingenic/bounties`；话题横幅 |
| 12 | 首页是一个页面，而不是帖子列表 | 可注册的首页、可配置区块、栏目卡片、推广位、外链按钮、合作平台、页脚栏目 | `/` 与 `/ingenic/home` |
| 13 | 中英双语、读起来像 Ingenic 的论坛 | 天蓝色调、三块式侧边栏、双语字符串、语言切换、更宽的版面和更清晰的边框 | 主题 |
| 14 | 把论坛接到 AI 客户端 | MCP 落地页，带端点和客户端步骤；悬浮助手接入 AI 机器人 | `/ingenic/mcp`；右下角机器人 |
| 15 | 可部署、可解释 | 插件与主题分仓；部署、导入和本使用文档均有中英两版 | 仓库与 `docs/` |

### 未包含

以下内容讨论过，但这一版有意不做：

- 帖子与回复的中英互译（属于另一个项目）。
- 把中文论坛的既有内容迁移到本站。
- 文档页头里的芯片选择器 —— 按确认的方案，选择器在文档控制栏里。

## 3. 功能地图

| 区域 | 会员可以 | 管理员可以 |
| --- | --- | --- |
| 论坛 | 阅读、发帖、回复、点赞、举报、收藏、私信、搜索；在话题上选择已有标签 | 分类、群组、信任级别、站点设置 —— 全部是 Discourse 原生能力；按版块配置权限和标签词表 |
| 标签与状态 | 发帖时选择标签；在标题旁看到公告、已解决、高赞 | 新建标签、指定颜色；把状态标签交给采纳和点赞自动维护 |
| 在线文档 | 选系列和芯片、切版本、搜索、阅读、上一页/下一页、进入论坛讨论 | 建产品树、版本和页面；控制发布；授予范围内的编辑权限 |
| 下载中心 | 筛选目录；直接下载、填写开发者资料、申请权限、用积分解锁 | 上传文件、设置访问级别和积分价格、审核申请、授予或撤销权限、查看下载记录 |
| 开发板 | 按类型和芯片筛选、查看弹窗、打开申请或购买 | 建卡片，设置类型、芯片、链接、售罄开关、规格、发布状态和顺序 |

| MCP / 助手 | 复制 MCP 端点并连接客户端；打开助手 | 开启或关闭核心 MCP 服务器和 AI 机器人 |

## 4. 会员入门

### 4.1 登录

使用站点提供的方式登录。Ingenic 扩展没有增加或修改认证，所以账号、重置密码、邮箱验证和第三方登录的行为与任何 Discourse 论坛一致。

部分下载和全部悬赏需要账号；阅读论坛、文档和开发板目录不需要。

### 4.2 侧边栏导航

左侧边栏分为三块：

- **论坛**（无标题）：发布新帖、首页、官方公告、技术讨论、开源版块。
- **开发者资源**（有标题）：在线文档、SDK 与固件下载、开发板、MCP。
- **会员块**（无标题，Discourse 的社区分区）：站点反馈、话题、高分悬赏、积分、全部分类、更多。

MCP 位于开发板商店下面，只在站点的 MCP 服务器开启时出现；站点反馈只在站点有这个分类时出现。

鼠标停在**技术讨论**上会展开一个面板，里面是各系列（T、C、X、MCU）。鼠标再停在某个系列上，该系列下的型号会在旁边的第二个面板里展开，所以无论一个系列有多少型号，系列列表都保持一行一个，不会把下面的内容挤出去。**开源版块**是导航里紧挨着它下面的那一行，不是这个面板里的一行：它自己是顶层分区，悬停时展开它的两个子版块。只有这两行带箭头、会在悬停时展开；侧边栏其余部分都是普通列表。

站点可能允许折叠分组或筛选侧边栏，那些是 Discourse 自带控件。开发者资源分组的标题可以由管理员改名，整个列表也可以在站点设置里替换，所以具体站点的文字可能和上面略有不同。

Discourse 自带的**标签**与**聊天**分组在此站点不显示。标签在这里用来给帖子加注或标示状态，不是第二种浏览方式，所以标签列表不出现在侧边栏（见 4.4）。本站也未启用聊天。

### 4.3 首页

首页由区块组装：热门栏目、最新或热门讨论、下载、开发板、推广位、悬赏和每周贡献榜。显示哪些区块、顺序、宽度和行数由管理员设置。

**每周贡献者**区块按会员本周获得的积分排序。它展示的是积分流水，不是另一套分数。

### 4.4 发帖与讨论

发帖、回复、引用、@、点赞、收藏、通知和举报都是标准 Discourse 行为。有三项 Ingenic 功能挂在话题上：

- **悬赏横幅**：话题带有进行中的悬赏时，显示在帖子上方（见第 9 节）。发帖框里的**悬赏**字段可以在写首帖时就把悬赏设好（见 9.2）。
- **官方身份标识**：显示在管理员指定的群组成员名字旁边。
- **标签**说明帖子讲什么、处于什么状态。发帖时可以从已有标签中选择；新建标签是管理员的事，这样词表才是一套词表，而不是一堆一次性的写法。

有三个标签表示状态，而不是主题：**公告**、**已解决**、**高赞**。只有管理团队可以打。**已解决**在提问者采纳答案时自动打上——必要时管理团队可代采纳——取消采纳后撤回。**高赞**在话题所有正常回复的点赞总数达到阈值时自动打上，默认 20 个赞，点赞数回落时自动撤回。管理员手工打上的**高赞**，这个自动任务永远不会移除。

列表里每条帖子的第一行是它所属的分区，那个徽章才是进入版块的入口；标签不承担第二个导航列表。

**开源版块**是一个分区，不是发帖的地方。页面顶部是两张子版块卡片——三方开源和官方开源——下面是两个子版块合在一起的话题列表。卡片进入对应子版块；合并列表给不关心项目属于哪一边的读者。父版块本身只读，不接收话题：发帖发生在两个子版块里。默认情况下官方开源只有管理员可以发帖，三方开源则任何有账号的会员都可以发布项目。

**技术讨论**比它多一层：每个系列（T、C、X、MCU）都是只读容器，讨论发生在系列下面的型号里。所以帖子列表里的分类名是型号——T33、T32Pro、T41、CW020、CW080、X2600 或 G32S10——系列页面则汇总它下面所有型号的话题。

### 4.5 语言

使用顶部语言菜单。每种语言都用它自己的文字书写 —— **EN** 和 **中文** —— 所以无论当前是哪种语言，菜单都读得懂。切换只改变界面；文档页面、下载等内容的语言跟随同一语言（有翻译时），没有翻译时回退到站点的默认内容语言。

## 5. 在线文档

### 5.1 打开阅读器

在侧边栏选择 **在线文档**。页面包含：

- 左侧控制栏里的**产品选择器**：先选系列，再选该系列下的芯片；
- 所选芯片的**版本选择器**；
- 搜索页面的**搜索框**；
- 按页面层级生成的、可折叠的**目录树**；
- **正文**，由 Markdown 渲染，带上一页和下一页。

还没有写文档的芯片会明确提示，而不是显示一个空的阅读器。

### 5.2 产品与版本

产品树恰好两级：**系列**（例如 `T Series`）和它下面的**芯片**（例如 `T33`）。同一棵树同时驱动下载筛选和开发板卡片的芯片字段，所以三处对芯片名称的理解始终一致。

一个版本只保存它改过的页面。如果某页在所选版本里没有改过，阅读器会显示最近的、改过该页的更早版本中的内容。这就是为什么新版本不需要复制整本手册，也是为什么老版本里修的一个错字仍能被新版本继承。管理员页面列表会显示每个继承页面当前来自哪个版本。

标记为 **latest** 的版本是芯片默认打开的版本。旧版本仍然可读，团队也可以把某个版本标记为不再维护。

### 5.3 搜索与导航

搜索检查所选芯片、所选版本下的页面，列出出现该文字的页面。目录树遵循后台设置的父子结构；上一页和下一页遵循同一阅读顺序。**在论坛讨论**会打开页面关联的话题；没有关联话题时打开站点的文档讨论分类。

### 5.4 分享链接

文档地址可以分享，也可以直接刷新：

```text
/ingenic/docs
/ingenic/docs/<series>
/ingenic/docs/<series>/<chip>
/ingenic/docs/<series>/<chip>/<version>
/ingenic/docs/<series>/<chip>/<version>/<page>
```

缺少某一段时，下一段会从上一段补全，所以短链接也能落到真实内容。阅读器会把短地址替换成规范地址，因此从地址栏复制到的始终是完整路径。

### 5.5 手机上

控制栏会收进阅读器的移动布局；目录树和产品选择器仍然可达，正文占满宽度。侧边栏本身变成 Discourse 标准的抽屉。

## 6. 下载中心

### 6.1 筛选目录

下载中心有三行筛选：

1. **芯片系列** —— 包括算法类目录入口。
2. **型号** —— 所选系列下的芯片。
3. **资源类型** —— SDK、固件、手册、数据手册、工具链、示例、发布说明，或团队定义的其它类型。

每条资源显示版本、平台、大小、发布日期和 SHA-256 校验值。筛选是按钮而不是下拉框；当前选择会填充，点另一个按钮立即改变列表。

### 6.2 三层访问权限

每条资源发布时属于以下三层之一：

| 级别 | 你会看到 | 你需要做 |
| --- | --- | --- |
| 登录即可 | 已登录显示**下载**，否则显示**登录后下载** | 登录 |
| 登录并填写开发者信息 | 第一次显示**填写资料** | 填写一次开发者表单；之后所有受限下载复用 |
| 登录、填写资料并审核 | 显示**申请权限** | 填写表单、提交申请，等待团队审核通过 |

开发者表单询问团队配置的字段 —— 默认是姓名、公司、职位、国家或地区、联系邮箱、用途、项目阶段、预计年用量等。资料保存在账号上，而不是某一条下载上。

申请会进入管理员队列，并邮件通知团队配置的地址。通过后你会收到邮件，可以下载该资源。授权是**按账号、按资源**的：一个 SDK 的授权不会打开另一个，团队也可以撤销授权。授权还可以带有效期。

申请等待期间按钮显示**等待审核**。被拒绝时卡片显示**申请未通过**，并说明如何跟进。

### 6.3 需要积分的资源

有些资源还带积分价格。价格是在访问级别**之后**询问的，而不是替代它：需要审核又要积分的资源，仍然要先登录、填资料、通过审核，才会提到积分。

符合条件时，操作按钮会变成**用 N 积分解锁**（积分足够）或**需要 N 积分**（积分不足）。解锁是一次性付费 —— 买过之后，该资源可以反复下载。积分从下载页和积分页显示的余额中扣除。

### 6.4 下载

文件在权限检查后由论坛流式返回，不是一个可以绕过门禁到处转发的公开链接。保存的 SHA-256 可以用来确认文件字节完整。如果存储里缺少文件，论坛会提示资源不可用，并且不扣积分。

## 7. 开发板与样片

### 7.1 目录

**开发板**列出两类条目：**开发板**和**样片**。三行筛选与下载中心风格一致：

1. **类型** —— 开发板或样片。
2. **系列** —— 全部系列，或当前类型下的某个系列。
3. **芯片** —— 全部芯片，或所选系列里的某个芯片。

每个选项都是一个按钮：当前选项用主题色填充，其余选项保留可见边框。芯片行只列出属于所选类型和系列的芯片，所以每个选项点下去都有内容。切换类型会清空下面两行，因为它们描述的是刚刚离开的那一类。

三行筛选在浏览器里完成：目录只拉取一次，点筛选不再请求服务器。目录到达之前，网格先画出最终尺寸的占位卡片，真实卡片出现时页面不会跳动。

### 7.2 卡片与详情弹窗

每张卡片显示图片、名称、芯片、简短介绍和一段规格列表。点击卡片打开弹窗，里面是更长的详情、完整规格和同样的两个操作按钮。

弹窗里的详细介绍使用 Markdown 编写：链接、图片、列表、表格都能正常显示，因此文档链接或示意图直接写在介绍正文里，不再单独占一个字段。

### 7.3 申请、购买与售罄

卡片底部和弹窗里始终显示两个按钮：

- **申请** —— 打开该开发板的申请页。
- **立即购买** —— 打开购买页。
- 两个按钮都用主题色绘制。某个按钮的链接为空时，该按钮变淡、不可点击，另一个按钮保持可用。两个链接都为空就是两个变淡的按钮，此时并不算售罄。
- **售罄**是一个独立开关。打开后，卡片和弹窗左上角盖上灰黑色的售罄印章，两个按钮都变淡、不可点击。链接会保留，关闭开关后开发板恢复原样。

链接在新标签页打开。管理员可以随时修改任一链接，卡片在下次加载页面时跟随。

## 8. 积分

### 8.1 获得积分

默认规则：

| 动作 | 积分 |
| --- | --- |
| 发起讨论 | 5 |
| 在讨论中回答 | 2 |
| 你的帖子被点赞 | 1 |
| 你的回答被采纳 | 15 |

数值、名称和顺序都可以在后台修改。规则可以停用或设为 0，不会删除已经写下的流水。默认管理员和版主不获得积分，但管理人员的点赞仍然算给发帖会员。

如果帖子被删除、点赞被取消或答案被取消采纳，该动作获得的积分会用一条相反的流水扣回。明细会同时显示两行，所以任何余额都能解释清楚。

### 8.2 查看积分

侧边栏的 **积分** 显示你的余额、当前价目表和自己的近期流水。页面只读，不显示他人的流水。未登录访客会被要求登录。

### 8.3 使用积分

积分在下载中心消费，用于带价格的资源。解锁对该账号永久有效。积分不能在会员之间转让；唯一例外是悬赏，它把积分转给被采纳答案的作者。

## 9. 高分悬赏

### 9.1 什么是悬赏

悬赏是会员在**自己的话题**上预留一笔积分，并全额支付给写出被采纳答案的人。它让一个难题值得别人花一下午。

积分是**托管**的，不只是口头承诺：挂出悬赏时积分立即从余额扣除，所以悬赏期间不能拿这笔积分去下载。默认每笔 50 到 5000 积分，悬赏有效期 14 天；上下限和天数都是站点设置。

每个话题同时只能挂一笔悬赏。只有在允许采纳答案的分类里才能挂；该功能还需要积分系统和已解决（solved）插件开启。

### 9.2 挂出与结算

新话题可以在发布的同时带上悬赏：在发帖框的**悬赏**字段里填金额，话题一创建悬赏就挂出。金额超过余额时，发帖框会询问是调整金额，还是不带悬赏发帖——不带悬赏发出去的话题，之后仍可在帖子页挂出。金额超过论坛上限时，字段会提示并等待一个更小的数字。

在已有话题上挂出：

1. 打开自己的话题。
2. 选择**为这个问题设置悬赏**，输入允许范围内的数额并提交。积分在这一刻离开余额。
3. 采纳答案时，全额支付给答案作者。采纳就是支付，没有单独的放款步骤。
4. 事后取消采纳**不会**把积分扣回。答题人可能已经花掉了。如果必须纠正错误，管理员可以手工调整两个账户。

必要时，管理人员可以代替提问者采纳答案。

### 9.3 撤回、过期与删帖

- 提问者可以撤回进行中的悬赏，积分立即退回。
- 截止前无人回答时，定时任务关闭悬赏并退款。
- 永久删除话题会关闭悬赏，退回仍然托管的部分。把话题移入回收站不会退款；悬赏继续有效到截止时间，在回收站期间从悬赏板消失。
- 关闭悬赏功能会停止新悬赏，但已经挂出的仍会退款。

### 9.4 悬赏板

侧边栏的 **高分悬赏** 列出全站进行中的悬赏，按金额从高到低，显示问题、金额和剩余时间。话题页上的横幅显示悬赏、发起人，以及提问者的撤回入口。结算后，横幅说明支付了多少、付给了谁。

## 10. MCP 与 AI 助手

### 10.1 MCP 页面

模型上下文协议（MCP）让 AI 助手访问论坛的工具和数据。社区分组里的 **MCP** 打开一个落地页，包含：

- 服务器端点，即站点自己的地址加 `/mcp`；
- 复制按钮；
- 连接客户端的三步：添加端点、登录并批准、开始提问；
- Claude Code 和 Visual Studio Code 的现成命令，以及其他支持远程 HTTP MCP 的客户端说明；
- 已批准客户端能看到什么的说明。

已批准的客户端以批准它的账号身份行动，只能看到该账号能看到的分类、话题和帖子；撤销授权后立即失效。站点管理员在 **后台 → MCP** 管理服务器和已批准客户端。

如果站点没有开启 MCP 服务器，页面会说明原因，侧边栏链接也会隐藏。

### 10.2 助手

右下角的机器人按钮打开 Ingenic 助手面板，说明助手的用途，并进入 AI 机器人的对话。未登录访客会被要求先登录，登录后回到助手。

助手会基于论坛回答，并在可能时指向文档。答案由 AI 生成，重要内容请对照文档核实。只有站点开启 AI 机器人时按钮才出现。

## 11. 管理员指南

### 11.1 界面在哪里

插件拥有的全部界面都在 **后台 → 插件 → Ingenic** 下。打开其中任意一个，页面标题下都会出现插件的标签栏 —— **文档**、**开发板**、**权限**、**权限矩阵**、**版块权限**、**标签配色**、**下载**、**积分**、**站点内容** —— 点标签即可切换。后台侧边栏只有 **Ingenic** 一个入口，打开的是**文档**界面。每个界面也各有自己的地址，适合收藏或直接链接：

| 界面 | 地址 | 管理内容 |
| --- | --- | --- |
| 文档 | `/admin/plugins/discourse-ingenic/documentation` | 系列、芯片、版本、页面 |
| 开发板 | `/admin/plugins/discourse-ingenic/boards` | 开发板与样片卡片 |
| 权限 | `/admin/plugins/discourse-ingenic/permissions` | 按芯片授予文档、下载、开发板管理权 |
| 权限矩阵 | `/admin/plugins/discourse-ingenic/group-permissions` | 自定义用户组可以管理哪些后台页面 |
| 版块权限 | `/admin/plugins/discourse-ingenic/category-permissions` | 分类 × 用户组的发帖与阅读级别 |
| 标签配色 | `/admin/plugins/discourse-ingenic/tag-colours` | 每个标签的颜色系列 |
| 下载 | `/admin/plugins/discourse-ingenic/downloads` | 资源、申请、授权、分类、下载记录 |
| 积分 | `/admin/plugins/discourse-ingenic/points` | 规则、调整、余额、流水 |
| 站点内容 | `/admin/plugins/discourse-ingenic/site` | 首页布局、首页卡片、推广位、外链按钮、合作平台、页脚 |

范围管理员只能看到被授权的文档、开发板和下载资源。申请队列、授权列表、下载记录、积分和站点内容仍然只有管理员可用。权限、权限矩阵、版块权限和标签配色四个页面也只有管理员可用，因为它们决定的都是「谁还能做什么」。服务端强制执行这一点；隐藏按钮不是边界。

添加第一批内容之前，先部署插件和主题，并运行分类初始化任务 —— 见 [`DEPLOY.zh-CN.md`](../DEPLOY.zh-CN.md) 和 [`docs/seeding.zh-CN.md`](seeding.zh-CN.md)。

### 11.2 文档

1. **建系列**。填写名称、slug 并从下拉框选择语言（只列本站真正提供的语言）。系列是产品树的一行。点 ✎ 可以修改名称、slug、语言和发布状态；已有行如果当初被存成了 `en`，在这里改回本站语言即可，不需要删除重建 —— 其下仍是 `en` 的型号、版本和页面会一起改过来，刻意设成其它语言的行不受影响。
2. **在系列下加芯片**。芯片必须有系列作为父级；后台和数据库都会拒绝没有父级的芯片。
3. **给芯片加版本**。填写版本 slug（例如 `1.1.0`）、显示名称和顺序。一个版本可以标记为 **latest**。
4. **给版本加页面**。先选类型：**目录**只用于分组，在目录树中展开/收起，没有正文；**文章**有 Markdown 正文。父级从下拉框里选（不存在的父级不会再被静默丢到顶层）。发布开关决定读者能否看到。
5. **排序和编辑**：系列、型号、版本和页面行都有 ↑ ↓；页面只在同一父级内移动。版本顺序决定继承方向，页面顺序决定目录树顺序。点 ✎ 打开该行的编辑表单：系列/型号可改名称、slug、语言和发布状态；版本可改名称、slug、语言、发布日期和「已弃用」。有子行的行不能删除；先移除或移走子行。
6. **覆盖继承页面**：选择**在此版本覆盖**，页面在本版本变为可编辑；**恢复继承**会删除本版本的副本，回到更早的来源。

文章的正文用 Markdown 编写，正文框上方是一排工具：加粗、斜体、标题、引用、列表、代码和链接。选中文字再点工具，文字会被包起来；没有选中时，工具会插入占位文字并选中它，直接输入即可替换。选区跨行时用围栏代码块而不是行内代码；**链接**会把光标留在填写地址的位置。图片有三种进入方式：工具栏的图片按钮、把图片直接粘贴进正文框、把图片拖到正文框上。图片通过 Discourse 自己的 `/uploads.json` 上传，插入为 `![文件名](upload://…)`，因此阅读器和后台预览都会像解析帖子图片一样解析它们，不需要额外配置。上传期间保存按钮保持禁用；上传被拒绝（格式不对或超过大小限制）时，正文框下方会说明原因。可以一次选择或拖入多张图片，它们会依次插入，之间空一行。

已发布的页面对读者可见；未发布的页面不在目录树里，直接请求会返回未找到。取消发布一个目录会把整节内容一起隐藏（包含下面已发布的文章），不会把它们挪到顶层。一个没有任何自有页面的版本，直接继承前一个版本的页面。

产品树被三个功能共用，所以要在下载和开发板之前建好：文档用它做选择器，下载用系列/型号筛选，开发板用每张卡片的芯片。

### 11.3 下载

下载界面最多有五个标签页：

- **资源** —— 新增和编辑资源。字段包括名称、目录（`chip` 或 `algorithm`）、产品 slug、分类、版本、语言、平台、架构、访问级别、积分价格、上传文件或文件 URL、文件大小、校验值、发布日期、顺序、描述和发布状态。
- **申请** —— 访问申请队列。打开一条，阅读申请人的开发者信息，填写备注，然后**通过并授权**或**拒绝**。授权可以设置有效期。
- **授权** —— 所有生效中的授权，按账号和资源，可以撤销。
- **分类** —— 资源类型筛选用到的标签。停用一个标签后，其下资源仍留在列表里，只是未归类，可以逐条重新分类。
- **下载记录** —— 谁在什么时候下载了什么。只有管理员可见，因为其中包含账号。

上传文件会存到配置的下载目录（Web 根目录之外）并计算 SHA-256。文件只在权限检查通过后由论坛流式返回。如果配置的存储目录不可写，界面会在尝试上传前说明；把 `ingenic_download_storage_path` 指向可写卷。

三层访问权限见 6.2。积分价格是可选的，只在文件真正发放时扣除。

**撤下资源不是删除。** 关闭**发布状态**只是让下载中心不再提供该文件，其他一切都保留：资源行连同描述、链接、已存文件和校验值仍在「资源」列表里，引用它的申请、授权和下载记录也都留在各自标签页中，审计结果仍然完整。重新打开**发布状态**即可再次提供该文件，原有授权继续有效。下载界面不会从物理上删除任何资源。

### 11.4 开发板与样片

新增卡片后设置：

- **类型** —— 开发板或样片。
- **芯片** —— 产品树里的芯片。它把卡片归到系列下，让芯片名称与文档保持一致，也是芯片筛选的依据。芯片还不在树里的卡片可以手填名称。
- **申请 URL** 和**购买 URL** —— 链接为空时对应按钮变淡；缺少链接并不等于售罄。
- **售罄** —— 打开后卡片和弹窗盖上售罄印章，两个按钮都变淡。链接会保留，方便补货后恢复。
- **介绍**、**详情**、**规格**（每行一条）、**图片 URL**、**顺序**和**发布状态**。**详情**使用 Markdown，弹窗显示的就是它，可以在其中插入链接和图片。

**撤下卡片不是删除。** 关闭**发布状态**会把卡片从公开目录移除，其余内容原样保留：卡片行连同正文、规格、图片和两个链接仍在「开发板」列表里，随时可以重新发布。开发板界面不会从物理上删除任何卡片。

### 11.5 积分

- **规则** —— 编辑每个动作的分值、名称、顺序和是否启用。设为 0 或停用只停止未来发放，不动流水。没有删除，因为旧流水仍引用该规则。
- **调整一个账户** —— 选择会员，输入正数或负数以及原因。调整会像其它流水一样写入账本。
- **余额** —— 每个持有积分的账户及其最后变动时间。
- **近期流水** —— 最近一百条，最新在前。被扣回的发放会出现两次。
- **重算全部余额** —— 从流水重建余额缓存。恢复或导入之后，或数字看起来不对时运行。

站点设置里可以关闭积分。已有余额和流水不受影响，管理员手工调整仍然可用。

### 11.6 权限

权限分两层，回答的是不同的问题。

**一个组能管理什么。****权限矩阵**把一整块管理页面授予一个自定义用户组：在线文档、开发板、下载中心、积分或站点内容。勾选表示「所有产品」，而不是「这个产品」。自动组（版主、信任级别、所有人）不在列表中：给「所有人」打勾等于把管理页面交给每一位访客，这不该由一个复选框顺手决定。

**一台芯片由谁负责。****权限**界面围绕产品树组织。一台芯片可以有三个互不相同的负责人——它的文档、它的下载和它的开发板——因为 T33 的文档和 T33 的 SDK 往往是不同的同事。在左侧选择系列或芯片，再选对应工作的标签页，然后按用户名、姓名或组名搜索成员或用户组。授予系列的权限会被系列下的每台芯片继承；芯片的标签页把它们标为「继承」，撤销要在系列上做，也就是授予的地方，而不是复制一份到子级。产品树出现之前针对单个页面、开发板和下载的授权单独列在下方，仍然可以撤销。

每次增删改查都在服务端检查，所以隐藏按钮只是展示层。

**论坛版块。****版块权限**界面按分类设置每个自定义用户组可以在其中做什么。级别是 Discourse 自带的，并不是同一个动词的三种强弱：**不授权**、**只能看**、**可回复**（能回复但不能发起主题）、**可发帖**（能发起主题和回复）。一个完全没有任何用户组行的分类对所有组开放；如果一次保存会让原本有行的分类变成一行都没有，保存会被拒绝，因为那等于悄悄把它对所有人开放。自动组保持原样，本页只修改自定义组。

### 11.7 标签与状态

**标签配色**界面为每个标签指定五种颜色系列之一：天蓝用于一般讨论，科技蓝用于平台、工具与硬件，已解决用于有答案的问题，公告用于官方通知，高赞用于社区认可的好帖。颜色系列是固定的，以保证全站视觉语言一致；标签列表则来自站点本身——今天新建的标签无需发版就会出现在页面上。没有指定颜色的标签按名称推断，推断不出时使用天蓝。

词表是站点策略，不是口头约定：

- 只有管理员可以新建标签；任何登录账号都可以在发帖时选用已有标签。
- **公告**、**已解决**、**高赞**属于一个只有管理团队可以打标的标签组。会员看得到，不能自己添加。
- **已解决**跟随 discourse-solved 的采纳状态。**高赞**由定时任务统计话题所有正常回复的点赞数，与 `ingenic_high_like_threshold`（默认 20）比较：达标打上，回落撤回，但管理员手工打上的永远不会被移除。
- 标签不承担导航：Discourse 的标签分组已从侧边栏隐藏，话题上的分区徽章仍然是进入版块的入口。

### 11.8 站点内容

**站点内容**界面有六个标签页：

- **首页** —— 有序的区块列表：区块类型、标题、宽度（自动、全宽、主栏、侧栏）、行数、分类或栏目列表，以及是否显示“全部分类”链接。保存后替换主题的默认布局。
- **首页卡片** —— 热门栏目下的卡片。填分类 slug 可以借用它的地址、颜色、图标和主题数；也可以自定义名称、链接、描述、图标、图片、颜色和顺序。
- **推广位** —— 标题、角标、描述、按钮、背景图、语言、展示起止时间、顺序和发布状态。不填日期就一直在，直到取消发布。
- **外链按钮** —— 页脚“关注我们”一栏的按钮，与合作平台并排：名称、链接、内置图标或图片、是否显示名称、是否外链、顺序和可见性。
- **合作平台** —— 页脚“关注我们”一栏。每项是链接或二维码，带名称、图片或二维码图、可选说明和顺序。中文名称和中文说明可以填在英文旁边。
- **页脚栏目** —— 标题及其链接（名称、地址、是否外链、顺序、可见性）。栏目和链接都可以另填中文标题或中文名称。

页脚跟随论坛当前显示的语言：英文为必填，中文为可选；没有填写中文的条目会回退显示英文，而不是消失。因此两种语言写在同一条记录上，译者只需补全中文字段，不必改动其他内容。

首页区块类型有：栏目卡片、推广位、公告、讨论、最新话题、热门话题、热门帖子、某个版块的最近动态、下载、开发板、高分悬赏和每周贡献榜。

### 11.9 站点设置

最常用的设置在 **后台 → 设置**（搜索 `ingenic`）：

| 设置 | 用途 |
| --- | --- |
| `ingenic_enabled` | 扩展总开关 |
| `ingenic_nav_items` | 侧边栏条目的 JSON 列表：名称、图标、目标、分组、顺序、可见性 |
| `ingenic_homepage_blocks` | 首页区块的 JSON 列表（站点内容界面编辑的是同一个列表） |
| `ingenic_default_locale` | 缺少翻译时使用的内容语言 |
| `ingenic_docs_discussion_category` | 页面没有关联话题时“在论坛讨论”使用的分类 |
| `ingenic_download_storage_path` | 上传文件的存放位置；必须在 `public/` 之外 |
| `ingenic_download_admin_email` | 收到申请时通知的邮箱 |
| `ingenic_developer_form_fields` | 开发者信息表单的 JSON 描述 |
| `ingenic_official_groups` | 成员佩戴官方身份标识的群组 |
| `ingenic_points_enabled` | 开关积分获得与消费，不清空余额 |
| `ingenic_points_exclude_staff` | 管理人员是否不获得积分（默认开启） |
| `ingenic_bounties_enabled` | 开关新悬赏；已挂出的仍会过期并退款 |
| `ingenic_bounty_min_points` | 单笔悬赏下限（默认 50） |
| `ingenic_bounty_max_points` | 单笔悬赏上限（默认 5000） |
| `ingenic_bounty_expiry_days` | 无人回答的悬赏多少天后退款（默认 14） |
| `ingenic_high_like_enabled` | 开关自动打「高赞」标签的任务 |
| `ingenic_high_like_threshold` | 话题所有正常回复的点赞数达到多少时获得「高赞」（默认 20） |

`ingenic_nav_items` 是 JSON 数组，一个条目如下：

```json
{
  "key": "docs",
  "label": "Online Documentation",
  "icon": "book",
  "href": "/ingenic/docs",
  "section": "resources",
  "position": 4,
  "enabled": true
}
```

`section` 取 `forum`、`resources` 或 `member`；`position` 决定组内顺序。用 `"category": "technical-discussions"` 代替 `href` 可以指向 Discourse 分类。设置为空时使用主题默认列表；配置了列表就整体替换默认值。

### 11.10 主题设置

在 **后台 → 自定义 → 主题 → Ingenic Community → 设置**：

| 设置 | 用途 |
| --- | --- |
| `ingenic_locales` | 顶部切换器提供的语言及顺序 |
| `ingenic_sidebar_width` | 桌面侧边栏宽度（像素） |
| `ingenic_sidebar_position` | 左侧或右侧 |
| `ingenic_nav_order` | Ingenic 导航在 Discourse 自带侧边栏分组之上还是之下 |
| `ingenic_nav_title` | 开发者资源分组的标题 |
| `ingenic_hero_title` | 首页区块上方的可选大标题 |
| `ingenic_hero_subtitle` | 可选副标题 |

语言切换器还需要 Discourse 的 `allow_user_locale` 和 `set_locale_from_cookie` 设置。主色是 **Ingenic Light** 配色方案，用 Discourse 常规颜色选择器编辑。

### 11.11 内容语言

每个文档页面、下载资源和开发板记录都带语言。使用 Discourse 自己的代码 —— `en`、`zh_CN` —— 因为它们要和读者的界面语言比较。`zh-CN` 不是同一个代码，不会匹配。缺少翻译时按记录回退到 `ingenic_default_locale`，所以半翻译的站点仍能正常显示。

主题的界面字符串在 `locales/en.yml` 和 `locales/zh_CN.yml`；增加第三种语言就是增加一个键相同的文件。顶部切换器只提供 `ingenic_locales` 里列出的语言。

### 11.12 日常维护

- 恢复或调整分类后运行 `rake ingenic:doctor`；它会报告缺失的论坛版块。
- 插件通过 `DEPLOY.md` 里描述的 `ingenic:config` 任务导出和导入内容；用它在本站与其它站点之间搬运内容。
- 永久删除的会员会留下流水、申请和授权，账号名被清空；界面显示**已删除账号**。
- 永久删除话题时，会在删除话题行之前退回仍托管中的悬赏。

## 12. 故障排查

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 侧边栏没有 MCP 链接 | `mcp_server_enabled` 关闭 | 在 后台 → 设置 → MCP 开启 |
| 助手按钮不出现 | `ai_bot_enabled` 关闭，或未安装 discourse-ai | 开启 AI 机器人；按钮会隐藏，而不是链到空处 |
| 下载显示“登录后下载” | 该资源至少需要账号 | 登录 |
| 每次都要求填写开发者信息 | 资料没有保存成功，或站点表单字段变了 | 重新提交；检查必填字段 |
| 申请一直显示“等待审核” | 还没人处理，或通知邮箱为空 | 查看 后台 → 下载 → 申请；设置 `ingenic_download_admin_email` |
| 显示“申请未通过” | 团队拒绝了这次申请 | 联系团队；情况变化后可以再次申请 |
| 显示“需要 N 积分” | 余额低于资源价格 | 通过贡献赚取积分，或联系团队 |
| 无法挂悬赏 | 积分或 solved 关闭、话题不是自己的、分类不允许采纳答案，或已有进行中的悬赏 | 检查分类和站点设置 |
| 文档页面无法编辑 | 它是从更早版本继承的 | 选择**在此版本覆盖**，或编辑来源版本 |
| 阅读器里缺少某页 | 页面未发布，或其父页面未发布 | 在 后台 → 文档 发布 |
| 上传失败 | 下载存储目录不可写 | 把 `ingenic_download_storage_path` 指向 `public/` 之外的可写卷 |
| 首页看起来是空的 | 扩展或主题被关闭，或没有配置区块 | 检查 `ingenic_enabled`、默认首页设置和 站点内容 → 首页 |
| 内容语言不对 | 记录的语言代码和读者语言不匹配 | 使用 `en` 或 `zh_CN`；检查 `ingenic_default_locale` |
